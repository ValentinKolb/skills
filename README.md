# ValentinKolb skills

Small agent skills for disciplined coding and concise documentation.

## Install

```bash
bunx skills add ValentinKolb/skills
```

`coding-workflow` uses Dex for task tracking. Install Dex and its skill as well:

```bash
bun add -g @zeeg/dex
bunx skills add dcramer/dex
```

## Skills

- `coding-workflow` - Explore, plan, then execute. Keeps changes scoped and verified.
- `docs-writer` - Writes terse READMEs, guides, explanations, and user-facing copy.

## Recommended skills

- [Matt Pocock skills](https://github.com/mattpocock/skills) - practical engineering workflow skills.
- [Fallow skills](https://github.com/fallow-rs/fallow-skills) - codebase intelligence for JavaScript and TypeScript.
